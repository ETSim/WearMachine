# IWear

## Overview

IWear provides detailed instructions and necessary files to build a specialized wear measurement apparatus using a GelSight bench. This system precisely calculates wear on various surface materials, offering reliable data for research and industrial applications.

## Purpose
- Evaluating wear performance of different materials
- Analyzing frictional interactions
- Validating simulation models with real-world data

## Components Required
- GelSight bench
- Custom-built fixtures (CAD files included)
- Load sensors
- Linear actuators
- Control and data acquisition system
